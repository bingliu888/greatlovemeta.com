# GreatLove Meta.Guru Product Roadmap

## Internal UI consistency rule

GreatLove Meta.Guru keeps the same common interaction model and feature depth as the established Guru product system. Public headers, menu order, signed-in account popup, Dashboard priorities, News, Events, Community, Project, pricing, referrals, readability, and responsive behavior must remain structurally consistent. Game-specific lessons, terminology, imagery, colors, and all application data remain independent.

This is an internal engineering rule. Public copy must never mention, compare, combine, or explain any relationship with another website. Every public statistic, member count, task, update count, and milestone refers only to GreatLove Meta.Guru.

Any common UI change is reviewed against the equivalent major pages before deployment. A change is not complete when the matching common surface silently diverges.

- `DONE` Global News, Events, Community, and Project navigation.
- `DONE` Member dashboard with referral copy and native sharing.
